# Myesha Starks | Motion Picture Hairstylist

Portfolio website for Myesha Starks, an Emmy-nominated Department Head and Key Hairstylist with over two decades of film and television credits.

**Live site:** [myeshastarks.com](https://myeshastarks.com)

## Features

- **Filterable gallery:** sort work by Signature Looks, On Set, Natural Hair, and Period & Character
- **Lightbox viewer:** click any image to view it full-size, with captions and previous/next navigation
- **Responsive layout:** works on phones, tablets, and desktops
- **Social sharing previews:** Open Graph tags give the site a proper title, description, and image when shared
- **Performance and accessibility:** lazy-loaded images and descriptive alt text on every photo

## Built with

Plain HTML, CSS, and JavaScript. No frameworks or build tools.

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and content |
| `style.css` | Layout, typography, and responsive styling |
| `script.js` | Gallery filtering and lightbox behavior |
